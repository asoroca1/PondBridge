# Fall Rollout Remediation Tracker

Last updated: 2026-07-26

## Scope and rollout assumptions

- Scope: shared PondBridge platform behavior, implemented locally before any
  production rollout.
- Control: existing camps without explicit new settings retain their current
  behavior. Cedar is treated as a control tenant until a targeted rollout is
  approved.
- Targeting: tenant IDs and server-owned settings are authoritative. Camp names,
  display text, host substrings, and client-only flags are not rollout gates.
- Status values: `DONE`, `IN PROGRESS`, `READY FOR VALIDATION`, `PLANNED`, and
  `BLOCKED`.
